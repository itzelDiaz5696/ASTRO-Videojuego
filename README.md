# ASTRO-Videojuego

Este es un proyecto académico en desarrollo, creado con **Unity** en un entorno **3D**. Se trata de un videojuego de combate en el que dos personajes aliados se enfrentan a un temible enemigo alienígena.

## Características actuales:
-  **Plataforma:** Unity 3D
-  **3 personajes implementados:**
  - 2 aliados (controlables por el jugador)
  - 1 enemigo (alien)
- **Sistema de combate:** 1 humano y su mascota contra un alien
-  **Estado:** En desarrollo / No concluido

## Próximas mejoras:

- Sistema de IA para el enemigo
